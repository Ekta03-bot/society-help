# Project Scope

## In Scope for MVP

- Register domestic helpers
- Register flats
- Assign helpers to one or more flats
- Generate a unique helper ID
- Generate a QR code for each helper
- Scan helper QR code at the society gate
- Validate whether the helper is active
- Record helper entry time
- Record helper exit time
- Display daily gate activity to the society administrator

## Out of Scope for MVP

- Aadhaar number storage
- Biometric fingerprint storage
- Iris scanning
- RFID/NFC hardware
- Salary calculation
- Payment management
- Police API integration
- Facial recognition
- Native Android or iOS application
- Advanced notifications
